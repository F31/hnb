# Observability and Monitoring

## Metrics

### Publish/ACK Latency

| Metric | Type | Labels | Description |
|--------|------|--------|-------------|
| `nats_publish_latency_ms` | Histogram | subject, stream | Time from DB write to JetStream ACK |
| `nats_ack_latency_ms` | Histogram | consumer, subject | Time from delivery to ACK |
| `nats_consumer_lag` | Gauge | consumer, stream | Number of pending messages for consumer |
| `nats_redelivery_count` | Counter | consumer, subject | Number of message redeliveries |
| `nats_outbox_age_seconds` | Gauge | - | Age of oldest pending OutboxEvent |
| `nats_failed_subject_count` | Gauge | subject | Number of messages in failed subject |
| `nats_queued_operation_seconds` | Gauge | - | Age of oldest Queued operation |
| `nats_stream_bytes` | Gauge | stream | Total bytes in stream |
| `nats_stream_messages` | Gauge | stream | Total messages in stream |

### Alert Rules

| Alert | Condition | Severity | Action |
|-------|-----------|----------|--------|
| `OutboxAgeHigh` | outbox_age > 5m | Warning | Check Outbox Relay and NATS connectivity |
| `OutboxAgeCritical` | outbox_age > 15m | Critical | Escalate; potential data loss |
| `ConsumerLagHigh` | consumer_lag > 1000 | Warning | Scale consumer or check for processing issue |
| `ConsumerLagCritical` | consumer_lag > 10000 | Critical | Investigate consumer failure |
| `RedeliveryRateHigh` | redelivery rate > 10/min | Warning | Check for poison messages |
| `FailedSubjectGrowing` | failed_subject_count > 100 | Critical | Manual redrive required |
| `NATSDown` | nats_up == 0 | Critical | NATS cluster unavailable |
| `PublishLatencyHigh` | p95 publish_latency > 5s | Warning | Check relay and broker performance |

## Distributed Tracing

### Correlation IDs

Every message Envelope carries:
- `correlationId`: Root trace ID (generated by API on Operation creation)
- `causationId`: Parent message ID (set by publisher)
- `operationId`: Operation being executed
- `stepId`: Step being executed

### Trace Context Propagation

```
API Request (correlationId=X)
  -> Outbox Write (causationId=X, messageId=Y)
  -> JetStream Publish (correlationId=X, causationId=Y)
  -> Worker Receive (correlationId=X, causationId=Y)
  -> Provider Call (traceparent derived from correlationId)
```

### Logging

- All logs include `correlationId`, `operationId`, `stepId`, `messageId`
- Message payload content is NEVER logged (only metadata)
- Forbidden field violations are logged with field name but not value
- Failed subject entries are logged with original message metadata
- NATS connection status changes are logged

## Dashboard

A Grafana dashboard with the following panels:

1. **Message Throughput** (line chart): messages/sec by stream
2. **Consumer Lag** (table): consumer, stream, lag count
3. **Publish Latency** (heatmap): p50/p95/p99 latency
4. **Redelivery Rate** (line chart): redeliveries/min by consumer
5. **Outbox Age** (gauge): oldest pending event age
6. **Failed Subject** (table): subject, message count, oldest message
7. **Operation Queue** (gauge): number of Queued operations, oldest age
8. **Stream Storage** (bar chart): bytes per stream
