## 迁移

- `application_delivery_bindings` 追加式保存每次应用交付 revision。
- 固定字段：tenant、target、namespace、release id/version、revision、resource UID、

## 查询

新增 `GET /api/v1/application-deliveries`：

- 支持 `targetId`、`releaseId`、`namespace`、`limit`。
- 以受信 tenant 强制过滤 `tenant_id`，不能通过 query 扩大租户范围。
- 每个 `(target, namespace, release)` 返回最高 revision。
- `targetId` 非 UUID 在查询前返回 400。
- 响应包含固定引用和观测水位，不返回 Secret/凭据。

实机插入临时 revision 1/2 后：

```text
release=lab-release -> [("2.0.0", 2, "lab-uid-2", "lab-route-2")]
invalid targetId -> HTTP 400
```

临时行随后删除，未保留测试交付数据。
