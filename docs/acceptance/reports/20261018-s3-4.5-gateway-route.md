## 实现

新增 `cmd/gateway-provider/internal/engine/gateway/route_binding.go`：

- 类型化 `RouteBinding`：namespace/name/Gateway/hostname/path/Service/port/external URL；
- 创建/更新 HTTPRoute，不接收任意 Manifest；
- 只有同时满足以下条件才成功：
  - HTTPRoute `Accepted=True`；
  - HTTPRoute `ResolvedRefs=True`；
  - Gateway `Programmed=True`；
  - 外部 HTTP probe 2xx，且包含期望 marker；
- CRD 创建返回 NotFound -> `HTTPRoute CRD is not installed`；
- Route 状态失败/超时 -> 不返回成功；
- 外部连接失败/非 2xx/缺少 marker -> 不返回成功。

## 实机结果

实际 Gateway：

```text
hnb-gateway/hnb-lab
class=hnb-traefik
ADDRESS=10.9.14.115
PROGRAMMED=True
```

成功 route：

```text
hnb-lab-probes/probe-app2
host=app2.hnb.test
backend=probe-server:8080
probe=http://10.9.14.115/ (Host: app2.hnb.test)
body=hnb-persist-after-recreation-20261018
```

输出：

```text
route accepted, gateway programmed, external probe passed
```

失败语义：

| 场景 | 结果 |
|---|---|
| backend Service 不存在 | `BackendNotFound`，Route 未生效，超时失败 |
| GatewayClass 无 controller | `Gateway not Programmed`，Route 未生效，超时失败 |
| 外部端口不可达 | `connection refused`，probe 失败 |
| HTTPRoute CRD 缺失 | 单元测试返回 `CRD is not installed` |

未把 Gateway `Programmed` 或 Operation 成功当成入口可用；只有 probe 通过才成功。
