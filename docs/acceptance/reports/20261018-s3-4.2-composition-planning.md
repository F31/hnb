## 规划器

`cmd/apiserver/internal/application/deliveryplan`：

- 仅接受 `application-composition/v1` / `ApplicationComposition`；
- 组件仅允许 Deployment/StatefulSet/Service/PVC/Ingress；
- workload 镜像必须 `@sha256:`；
- PVC 必须有 storageClass 和正 storageBytes；Ingress 必须有 host；
- 依赖必须存在，拓扑排序稳定，检测环；
- 资源总量与 namespace quota 比较；
- 每个 SecretReference 按 tenant 校验；
- 固定 snapshot digest 必须能在该 target 的 capability snapshot 中找到；
- PVC 要求 snapshot 有 storageClass/CSI driver；Ingress 要求 Gateway API 版本；
- 输出只含 plan/step/dependsOn，不含凭据或任意 YAML。

## 实机预检

创建 `hnb-app` namespace，quota `4 CPU / 8192 MiB / 8192 GiB`。

| 请求 | 结果 |
|---|---|
| 单一 Deployment，snapshot 匹配 | 200，plan step `api` |
| `manifest` 未知字段 | 400，严格解码拒绝 |
| CPU 8 > quota 4 | 422 `QUOTA_EXCEEDED` |
| PVC，snapshot 无 storageClass/CSI | 422 `CAPABILITY_MISSING` |
| 不存在 SecretReference | 422 `SECRET_REFERENCE_NOT_OWNED` |

依赖排序/环/未知依赖/重复组件/非法 kind/未固定镜像由单元测试覆盖。
