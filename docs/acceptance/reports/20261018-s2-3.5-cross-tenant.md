## 迟到响应隔离

使用两条独立 HTTP 连接：

1. 先发送 A 的 cluster/readiness 请求但不读取；
2. 发送并读取 B 的请求（A 响应在客户端侧成为迟到响应）；
3. 再读取 A 响应。

结果：

```text
clusters A/B = 200/200
A_has_target = true
B_has_target = false
readiness A/B = 200/404
```

重复 20 次交错：

```text
interleaved_failures = 0
```

未发现共享响应缓存、token/tenant 串用或 B 获得 A 数据的现象。
