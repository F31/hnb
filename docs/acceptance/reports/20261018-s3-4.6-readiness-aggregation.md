## 聚合规则

`cmd/apiserver/internal/application/readiness`：

只有全部成立才 Ready：

- revision 与 binding 一致；
- resource UID 与 binding 一致；
- execution = succeeded；
- observation freshness = FRESH 且 generation/revision 不低于 binding；
- external probe = passed；
- volume read/write = passed。

失败 reasons：

```text
EXECUTION_FAILED / EXECUTION_PENDING
OBSERVATION_STALE / OBSERVATION_BEHIND
RESOURCE_UID_MISMATCH / REVISION_MISMATCH
EXTERNAL_PROBE_FAILED / VOLUME_READ_WRITE_FAILED
```

聚合不会修改 Operation 终态；执行成功但验证失败时，execution 仍显示 `succeeded`，
只有 `ready=false`。
