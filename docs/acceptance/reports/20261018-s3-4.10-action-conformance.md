## 目标 RBAC allow/deny

`hnb-app/hnb-provider`：

```text
create services -n hnb-app                 -> yes
update deployments -n hnb-app              -> yes
create/get/delete pvc -n hnb-app           -> yes
get secrets -n hnb-app                     -> no
create services -n default                 -> no
create namespaces                          -> no
```

HTTPRoute 仅 `hnb-lab-probes`/`hnb-app` 允许；Gateway 仅读取；无集群级写权限。

## 硬配额

ResourceQuota `hnb-app-hard`：

```text
requests.storage: 200Mi
persistentvolumeclaims: 2
used: 128Mi/1
```

- 请求 256Mi PVC -> admission 拒绝，PVC 不存在；
- 请求 64Mi PVC -> 允许，创建后按授权删除。

## 网络隔离

目标 CNI 实际执行 NetworkPolicy：

- default-deny ingress -> 同 namespace 也拒绝；
- allow `namespaceSelector=netpol-test` 后：
  - 同 namespace client -> TCP 可达；
  - `netpol-other` client -> connection refused。
- 测试 namespace 已清理。
