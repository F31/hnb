## 入口与执行路径

Portal：

```text
应用 -> 应用交付 (/application/delivery)
```

CLI：

```text
hnbctl application plan --composition-file FILE ...
hnbctl application status --delivery-id ID ...
hnbctl application delete-preview --delivery-id ID ...
hnbctl application deploy|upgrade|rollback|delete \
  --delivery-id ID --idempotency-key KEY ... [--approve]
```

执行路径：

```text
Portal / CLI -> apiserver BFF -> platform-api POST /v1/operations
             -> operation-worker step-requested
             -> kubernetes-provider /v2/steps:execute
             -> target Kubernetes
```

- BFF 不直接执行 Provider；Operation 由 platform-api 写入并投影。
- BFF 使用 applicationDelivery 作用域 delegation，保留 actor/correlation。
- `rollback`/`delete` 初始 `pending_approval`；Portal/CLI 可显式批准。
- CLI 在 token tenant 与 `--tenant-scope` 不一致时本地拒绝。
