## 删除预览

`GET /api/v1/application-deliveries/{id}/deletion-preview` 返回：

```text
Deployment demo            -> delete
Service demo-http          -> delete
HTTPRoute probe-upgrade    -> delete
PVC demo-data              -> retain
requiresDataCleanupAuthorization=true
retainVolumes=true
```

## Generation 墓碑与迟到 deploy

Deployment delete：

```text
last-action=delete
fencing-generation=5
replicas=0
```

迟到 deploy（generation 4）返回：

```text
deployment fencing generation 5 is newer than request generation 4
```

Deployment 保持 tombstone，未复活。

## 卷保留

```text

```

## 数据清理授权

测试 PVC `cleanup-data`：

- 未带 `data_cleanup_authorized=true`：
  `data cleanup requires explicit authorization`，未删除；
- 带显式授权和 expected UID：
  `{"action":"pvc.deleted", ...}`，PVC 不存在。

## 非托管资源拒绝

手工创建无 HNB owner 注释的 `foreign-data` PVC：

```text
pvc is not owned by this tenant/provider
```

PVC 仍存在，随后由集群管理员清理；Provider 未接管/删除。

## 权限

`hnb-provider` PVC Role 增加 delete，仅用于显式授权后的数据清理；Secret 仍不可读。
