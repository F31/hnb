## Provider 实现

### `pvc.deploy`

输入：`namespace`、`name`、`storage_class`、`size`。

- RWO + StorageClass + Requests.storage；
- owner/tenant/operation/step/idempotency/fencing/attempt 注释；
- 使用 WFFC 时返回 `Pending`，由工作负载消费后绑定；不把等待 Bound 当作创建失败；
- exact replay；更高 generation `FENCED`；旧 generation/spec 冲突；
- 非法 size 写入前拒绝。

### Deployment 挂载

```text
pvc_name + pvc_mount_path
secret_name + secret_mount_path
```

- 必须成对出现；
- PVC 读写，Secret 只读；
- 挂载路径必须绝对且不含 `..`；
- Provider 只引用 Secret 名称，不读取 Secret 内容；
- 修复 Secret volume 默认 `defaultMode=420`，保证 exact replay 可比较。

## 最小 RBAC

`hnb-app/hnb-provider`：

```text
create persistentvolumeclaims -n hnb-app -> yes
get persistentvolumeclaims -n hnb-app    -> yes
get secrets -n hnb-app                   -> no
```

Provider 不需要 Secret 读取权限；Secret 仅由 kubelet 挂载。
