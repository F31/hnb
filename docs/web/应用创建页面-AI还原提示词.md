# 应用创建流程 - AI Coding 还原提示词

三个页面共用同一套设计规范，建议先建立一份"设计系统"说明（放在提示词最前面或单独一次性告知AI），再分别还原三个页面，这样风格能保持统一。

## 〇、通用设计规范（放在每个提示词前面，或先单独发一次）

```
请使用 React + Tailwind CSS 实现以下企业后台管理系统页面。

设计规范：
- 主色：紫色 #6E3AF2 左右（按钮、选中态、步骤指示器高亮）
- 背景色：页面背景浅灰 #F5F6FA，卡片/表单区域白色 #FFFFFF，圆角 8px，轻微阴影
- 字体：系统默认无衬线字体，标题字号 14-16px 加粗，正文 14px，说明文字 12px 灰色 #909399
- 必填项：字段名前红色星号 *
- 输入框：浅灰边框 #DCDFE6，聚焦时变紫色边框，圆角 4px
- 顶部面包屑导航：灰色文字 + "/" 分隔，如"应用列表 / 创建应用"
- 步骤条：圆圈数字 + 文字，当前步骤紫色圆圈白字，未完成步骤灰色圆圈，步骤间用横线连接，已完成步骤显示✓
- 按钮：主按钮紫色实心圆角，次按钮白底灰边框
- 单选卡片（如资源类型选择）：卡片式，选中时紫色边框+浅紫背景+右下角紫色✓图标，图标+标题+描述文字三段式布局
- 整体使用 Ant Design 风格的表单组件也可（Select、Radio、Switch、Input等）
```

## 一、页面1：创建应用 - 基础配置（第一步）

```
实现"创建应用"向导的第一步"基础配置"页面，是一个三步流程的第一步（第二步"应用配置"、第三步"部署确认"）。

顶部：
- 面包屑：应用列表 / 创建应用

表单字段（从上到下，白色卡片容器）：

2. 版本：必填，单行文本输入框，placeholder"请输入版本"

- 右下角固定操作栏：白色背景，右对齐两个按钮"取消"（白底灰边）、"下一步"（紫色实心，主按钮）

```

## 二、页面2：创建应用 - 应用配置（第二步，长表单）

```
实现"创建应用"向导第二步"应用配置"页面，页面很长，由多个可折叠/分组的表单区块组成，每个区块标题左侧有一条紫色竖线装饰。

顶部同页面1：面包屑 + 步骤条（此时②应用配置为当前高亮，①基础配置显示已完成✓）

各分组区块（每块是独立白色卡片，标题加粗，部分标题右侧有蓝色ⓘ提示图标）：

1. 基本属性
   - 应用类型：横向Tab单选："无状态应用"（选中）、"有状态应用"、"守护进程"
   - 环境变量：说明文字 + "添加"按钮 + "快速添加"按钮，下方是表格（配置方式/变量名/值/操作三列），配置方式默认下拉"手动输入"
   - 容器规格：必填，说明"根据工作负载，默认应用CPU:4核，内存:8192MB"
     - 启动限额：说明"运行容器所需的最小资源限制"，CPU输入框(核)、内存输入框+单位下拉(GB)
     - 运行限额：说明"内存容器运行的最大资源限制"，CPU输入框（旁边显示"项目可用配额：999968.000核"）、内存输入框（旁边显示"项目可用配额：999968.000GB"）
     - 底部灰色说明文字（关于CPU/内存计算规则）
   - GPU调度：单选按钮组：不开启（选中）、独享GPU、hami GPU
   - 配置文件：+添加 按钮，表格（文件/上传路径/操作）
   - 控制器标签：+添加 按钮
   - 控制器注解：+添加 按钮
   - 副本数：数字输入框，默认值1

2. 健康检查（说明"用于判断容器是否正在正常运行"）
   - 存活性检查、可用性检查、启动检查：每行都是单选"关闭"（默认选中）、command、httpGet、tcpSocket
   - 底部"展示高级配置"折叠按钮（带箭头图标）

3. 回调函数（说明"用于生命周期钩子"）
   - 启动后回调：关闭(默认)/command/httpGet
   - 停止前回调：关闭(默认)/command/httpGet
   - 优雅停止超时时间：带 +/- 步进器的数字输入，默认30，单位s

4. 升级策略（说明"对容器升级策略进行配置，默认应用CPU:4核，内存:8192MB"）
   - 升级策略：单选 滚动升级(选中)/全新重建
   - 填写方式：单选 个数/百分比(选中)
   - 最大扩容：输入框默认25，单位%
   - 最大不可用：输入框默认25，单位%

5. 服务访问设置
   - 服务名称：输入框
   - 类型：单选 集群外访问(选中)/集群内访问
   - 开启IPv6：单选 是/否(选中)
   - 端口映射：+添加 按钮
   - 会话保持：开关，说明文字"根据在设置的会话保持时间，来自同一IP的请求将转发到同一pod进行处理"

6. 应用访问路径（说明"应用的访问路径，默认值，可通过IP:端口或path形式访问"）
   - 单个输入框

7. 启动命令
   - 运行命令：文本域，placeholder示例 "/bin/start\n或\nsleep 60"
   - 命令参数：文本域，placeholder说明"运行命令的输入参数，例如：--port=3306，多个命令参数可用行分隔"

8. 存储卷（说明"给容器提供额外存储，适用于持久化存储，同挂载CPU容器规格，默认应用CPU:4核，内存:8192MB"，右侧显示"项目可用配额：999950.000GB"）
   - +添加 按钮

9. 配置项（ConfigMap）：说明文字 + 添加按钮
10. 密钥（Secret）：说明文字 + 添加按钮
11. 节点亲和性（Node Affinity）：说明文字 + 添加按钮
12. 应用亲和性（Pod Affinity）：说明文字 + 添加按钮
13. 应用反亲和性（Pod Anti-Affinity）：说明文字 + 添加按钮
14. hostAlias域名映射：+添加按钮
15. 初始化容器：+添加按钮，下方有分隔线

16. 容器权限
   - 特权容器：开关（关闭），说明"启用后container可访问host设备等敏感资源"
   - Host Network / Host PID / Host IPC：均为 是/否 单选（否选中），带说明文字
   - Read Only Root Filesystem：开关
   - 运行用户Uid：下拉"手动输入" + 输入框，说明"有0表示以root用户运行，非0表示以对应uid运行"
   - Linux内核能力：下拉选择

17. 自动伸缩
   - CPU使用率：开关(关闭) + 百分比输入框，说明"当容器的CPU使用率超过阈值，系统将自动进行伸缩"
   - 内存使用率：开关(关闭) + 百分比输入框，同上

18. 应用诊断
   - 是否启用：开关（关闭）

19. 日志服务接入
   - 日志服务接入：开关（关闭）+ 上传路径输入框（禁用态）

20. 网络配置
   - +添加 按钮
   - 表格：容器网卡（类型下拉/网络下拉/子网下拉三列），示例行：虚拟专有云 / ovn-cluster-default(11.0.0.0/10) / ovn-default-default(11.0.0.0/10)
   - 下方显示"IPV4地址数量: 4587765" "IPV6地址数量: 0"
   - 默认网关：开关
   - 是否固定IP：开关
   - QoS限速：开关
   - 底部"隐藏高级配置"折叠按钮

底部固定操作栏：取消（白按钮）、上一步（白按钮）、下一步（紫色主按钮），右对齐。

技术要求：用 React 组件化拆分每个区块为独立子组件，用 useState 管理各字段值，长页面需要良好的垂直间距和分组视觉层次（区块间用较大的margin或分隔卡片阴影区分）。
```


## 使用建议

1. **先发通用设计规范**，让AI建立统一的视觉基调，避免三个页面风格不一致。
2. **按顺序还原**：先做页面1（简单表单），验证风格对不对，再做页面2（超长表单，建议要求AI拆成多个子组件文件而不是一个巨大组件），最后做页面3（弹窗，可以复用页面1里预留的触发按钮直接联调）。
3. **如果用 Claude Code / Cursor 等本地工具**，可以直接把这三张截图作为图片一起贴给AI，配合上面文字提示词，AI能"图文对照"效果会更准确，比纯文字描述省事很多。
4. 涉及具体业务字段（如自动伸缩阈值单位、网络子网格式）如果后续要接真实接口，建议在提示词里再补充"数据结构/接口字段"说明，AI生成的状态管理会更贴近真实需求。
