# 参考应用基线（S0 1.6）

状态：**blocked**。当前仓库没有已锁定的参考应用 v1/v2/故障版本 OCI 摘要，
也没有可执行发布物料、卷读写探针和外部探针。本文件固定所需条件，不用 fixture
摘要冒充真实应用。

## 1. 必须固定

| 项 | 要求 |
|---|---|
| v1 | 镜像 repository + **sha256 digest**、启动参数、配置、期望副本/端口 |
| v2 | 与 v1 可区分的新 digest/配置；保留数据兼容路径 |
| 故障版本 | 明确失败模式（启动失败/readiness 失败/数据不兼容），可重复复现 |
| 发布物料 | Chart/manifest、values、镜像 digest 锁定、依赖与版本 |
| 卷 | PVC/StorageClass、访问模式、容量、读写标记文件与校验 |
| 外部探针 | 域名/路径/TLS/期望状态码；真实入口地址与网络条件 |
| 数据标记 | 唯一写入标记、写入/回读/校验步骤、恢复后保留断言 |
| 证据 | 部署/升级/失败恢复/删除保留卷的真实运行报告与报告摘要 |

## 2. 禁止

- 用 `nginx:latest`、tag-only、fixture 摘要或本地临时构建冒充已锁定参考应用。
- 用“Pod Running”代替卷读写/外部探针/数据恢复断言。
- 在客户卷任意覆盖文件；探针只写授权目录并使用唯一标记。
- 把 1.8/1.9 的 synthetic readiness fixture 登记为应用 E2E。

## 3. 解除阻塞

项目方提供/批准参考应用仓库、三个版本 digest、发布 Chart 与目标环境入口后，
在独立业务集群执行 S3 黄金路径；在此之前 1.6 保持未完成。
